# Usage Guide

## Analyze a Log File

```bash
bash scripts/analyze.sh test_data/sample_fail.log
```

## Show Help

```bash
bash scripts/analyze.sh --help
```

## Generate Report

```bash
bash scripts/generate_report.sh
```

## Setup Environment

```bash
bash scripts/setup_env.sh
```
